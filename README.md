# ครูบอร์ด (KruBoard) — ระบบกระดานส่งงานออนไลน์

> **พัฒนาโดย: ครูก้องนที อุ่นเจริญ**
> สถาปัตยกรรม: **Frontend บน GitHub Pages** (PWA + รองรับถ่ายภาพจากกล้องมือถือ) + **Backend บน Google Apps Script** (เก็บข้อมูลใน Google Sheets และอัปโหลดไฟล์ลง Google Drive อัตโนมัติ)

---

## จุดเด่นและฟีเจอร์หลัก

- **สร้างกระดานอิสระใช้ได้ทั้ง 2 แบบ**: ทั้งกระดานส่งงานนักเรียนในห้องเรียน และกระดานส่งงานเอกสารของครู/กลุ่มสาระ/ฝ่ายบริหาร
- **มุมมอง 3 รูปแบบในทุกกระดาน**:
  1. **แบบกระดาน (Padlet Wall)** — การ์ดโพสต์หลากสีสไตล์ Padlet
  2. **แบบคอลัมน์ตามหมวดหมู่ (Shelf)** — แยกคอลัมน์ตามห้องเรียนหรือกลุ่มสาระที่กำหนดเอง
  3. **แบบตารางติดตามงาน (Table Tracker)** — ดูรายชื่อผู้ส่ง ไฟล์แนบ สถานะ และคะแนนได้ชัดเจน
- **อัปโหลดรูปภาพและไฟล์แนบตรงเข้า Google Drive อัตโนมัติ (Direct Resumable Upload สูงสุด 30 MB + Progress Bar 0–100%)**:
  - ส่งไฟล์ Binary ตรงเข้า Google Drive โดยไม่ผ่าน Base64/RAM ของ GAS จึงเร็วและเสถียรแม้ไฟล์ขนาดใหญ่
  - บีบอัดรูปภาพอัตโนมัติก่อนส่ง รองรับทั้งเลือกไฟล์ ลากวาง และถ่ายภาพจากกล้องมือถือ
  - รองรับ JPG, PNG, WebP, PDF, Word, Excel, PowerPoint, ZIP, MP4, MP3 (สูงสุด 30 MB)
  - แยกโฟลเดอร์ย่อยตามรหัสกระดานในโฟลเดอร์ `KruBoard_Uploads` บน Google Drive
  - มีระบบอัปโหลดสำรองและระบบดึงภาพสำรองผ่าน API อัตโนมัติ กรณีบัญชี Google Workspace ของโรงเรียนปิดการแชร์ไฟล์แบบสาธารณะ
- **ระบบสำหรับครูผู้ดูแล (Admin)**:
  - ล็อกอินด้วยรหัสผ่านที่เข้ารหัสแบบ Salted Hash + Session Token
  - สร้าง/แก้ไข/ล็อก/ตั้งรหัสผ่านเข้ากระดาน/กำหนดวันส่งงาน/เลือกธีมสี 7 แบบ (รวมลายกระดานไม้ก๊อก)
  - ตรวจงาน ให้คะแนน เขียนข้อเสนอแนะครู อนุมัติโพสต์ ปักหมุด และลบโพสต์/ความคิดเห็น
  - สร้าง **QR Code** และลิงก์เฉพาะแต่ละกระดาน พร้อมดาวน์โหลดภาพ QR ไปติดหน้าห้องหรือส่งเข้ากลุ่ม LINE
  - **ส่งออกข้อมูลเป็นไฟล์ CSV (UTF-8 BOM)** เปิดใน Microsoft Excel ภาษาไทยไม่เพี้ยน

## โครงสร้างไฟล์ในโปรเจกต์

```text
board กระดานส่งงานครู/
├── index.html           # หน้าเว็บหลัก (GitHub Pages Root)
├── manifest.json        # ตั้งค่า PWA (เพิ่มลงหน้าจอมือถือได้)
├── sw.js                # Service Worker สำหรับแคชไฟล์หน้าเว็บ
├── css/
│   └── app.css          # สไตล์และธีมกระดานทั้งหมด
├── js/
│   ├── config.js        # จุดใส่ลิงก์ Google Apps Script Web App (/exec)
│   ├── api.js           # ตัวเชื่อม GAS API (POST text/plain) + โหมดทดลองใช้
│   └── app.js           # โค้ดควบคุมหน้าเว็บและฟีเจอร์ทั้งหมด
└── gas/
    ├── Code.gs          # โค้ด Backend สำหรับวางใน Google Apps Script
    └── appsscript.json  # ตั้งค่า Timezone Asia/Bangkok และ OAuth Scopes
```

## ขั้นตอนการติดตั้งใช้งานจริง (ทำตามทีละขั้น)

### ขั้นที่ 1: สร้างฐานข้อมูล Google Sheet และ Google Apps Script

1. เปิด [Google Sheets](https://sheets.google.com) แล้วสร้างสเปรดชีตเปล่าใหม่ 1 ไฟล์ (ตั้งชื่อเช่น `ฐานข้อมูล ครูบอร์ด`)
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ `gas/Code.gs` ในโปรเจกต์นี้ไปวางแทน จากนั้นกด **บันทึก (Save)**
4. เลือกฟังก์ชัน **`setupSystem`** จากแถบด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)**
   - ระบบจะขออนุญาตเข้าถึง Google Sheets และ Google Drive → กดอนุญาต (หากขึ้นหน้าเตือน Google hasn't verified this app ให้กด *ขั้นสูง (Advanced) → ไปที่โปรเจกต์*)
   - เมื่อรันเสร็จ สเปรดชีตจะสร้างชีตทั้งหมด (`Config`, `Users`, `Sessions`, `Boards`, `Posts`, `Comments`, `AuditLogs`), โฟลเดอร์ `KruBoard_Uploads` บน Google Drive และบัญชีแอดมินเริ่มต้นให้อัตโนมัติ
5. ทำการเผยแพร่เป็น Web App:
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
   - กดรูปเฟืองเลือกประเภทเป็น **เว็บแอป (Web app)**
   - ตั้งค่า **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - ตั้งค่า **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก เพื่อให้หน้าเว็บ GitHub Pages เรียก API ได้โดยไม่ติดหน้าล็อกอิน)*
   - กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

> **หมายเหตุเมื่อแก้ไขโค้ด `Code.gs` ในอนาคต:** ทุกครั้งที่แก้โค้ดฝั่ง Apps Script ต้องไปที่ `Deploy → Manage deployments → กดรูปดินสอ → เลือก New version → Deploy` ไม่งั้นลิงก์ `/exec` จะยังรันโค้ดเวอร์ชันเก่า

---

### ขั้นที่ 2: เชื่อมต่อและนำ Frontend ขึ้น GitHub Pages

1. เปิดไฟล์ `js/config.js` แล้วนำ Web App URL ที่ได้จากขั้นที่ 1 มาวางในค่า `GAS_API_URL`:
   ```javascript
   GAS_API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
   ```
2. สร้าง Repository ใหม่บน [GitHub](https://github.com) (เช่น `kruboard`) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main`
3. ไปที่แท็บ **Settings → Pages** ของ Repository:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` และโฟลเดอร์ `/ (root)` → กด **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์เว็บไซต์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/` พร้อมใช้งานทันที!

## บัญชีผู้ดูแลระบบเริ่มต้น

- **ชื่อผู้ใช้:** `admin`
- **รหัสผ่าน:** `admin1234`

> แนะนำให้เข้าสู่ระบบครูผู้ดูแลแล้วไปที่เมนู **ตั้งค่า → เปลี่ยนรหัสผ่านผู้ดูแลระบบ** ทันทีหลังติดตั้งเสร็จ

## การทดสอบใช้งานในเครื่อง (Demo Mode)

หากยังไม่ได้ใส่ค่า `GAS_API_URL` ใน `js/config.js` ระบบจะทำงานใน **โหมดทดลองใช้ (Demo Mode)** โดยอัตโนมัติ สามารถทดสอบสร้างกระดาน ส่งงาน แนบรูป ตรวจให้คะแนน และแชร์ QR Code ได้ทันที หรือกดปุ่ม **ตั้งค่าการเชื่อมต่อ Sheet** บนแถบด้านบนเพื่อนำลิงก์ `/exec` มาทดสอบเชื่อมต่อได้ทันทีโดยไม่ต้องแก้ไฟล์ก่อน
